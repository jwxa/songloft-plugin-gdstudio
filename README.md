# Songloft GDStudio 插件

这是一个独立的 Songloft JS 插件，用于在插件页面中搜索 GDStudio 音乐。V1 采用“先试听、后手动入库”的流程，避免搜索结果自动污染曲库。

仓库地址：<https://github.com/jwxa/songloft-plugin-gdstudio>

## 当前能力

- 搜索、元数据和音频解析优先调用 GDStudio 官方公开 API，不依赖网页签名、Cloudflare Cookie 或 Python 运行时。
- 当且仅当酷我来源的 GDStudio 音频解析返回空链接时，使用 musicsquare 采用的酷我同源解析接口，以相同歌曲 ID 获取现成音频文件；不会自动切换到其他来源。
- 网易云、酷我和腾讯默认启用，可在插件页面持久化开关。腾讯使用 musicdl `QQMusicClient` 已收录的同源接口，解析失败时不会自动跨来源替换。
- 搜索失败时默认展示可操作的简洁提示，底层网络与上游错误仅在用户点击“查看详情”后通过弹层展示。
- 每个来源的搜索请求首次失败后会自动重试一次；第二次仍失败才显示错误提示。
- 支持“全部 / 网易云 / 酷我 / 腾讯”来源筛选、独立分页和单源失败隔离。
- 自动化测试全部使用可控模拟传输，不依赖真实 GDStudio 公网。
- 支持插件页面完整流式试听，满意后手动入库或下载到 Songloft `music_path`；下载保留上游格式，不执行转码。
- 试听解析期间立即显示加载动画；无损格式显示为“FLAC/APE · 无损”，不把上游返回的 `2000` 等名义值展示成精确固定码率。
- Android/iOS WebView 在音源解析完成后显示“播放试听”按钮，由用户再次明确点击启动播放；桌面端自动播放被策略阻止时同样优雅降级为该按钮。
- 已入库歌曲点击“主播放器播放”后会启动播放队列，并在支持导航桥接的 Songloft 客户端中打开全屏播放器。
- 下载提交为 Songloft 后台任务，页面轮询展示排队、准备、真实字节下载、写入曲库、完成或失败状态，不再让完整文件下载阻塞 QuickJS 请求。
- 支持将勾选歌曲批量加入 FIFO 下载队列；页面最大并发可配置为 1–3，默认 2，宿主另设全局并发保护。
- 单曲入库和下载前先验证音源可播放，避免写入已知无法播放的曲库记录。

## 开发

```bash
corepack pnpm install
corepack pnpm run validate
corepack pnpm test
```

构建产物位于 `dist/gdstudio.jsplugin.zip`。

## 私有安装

1. 执行 `corepack pnpm run validate` 生成并校验插件包。
2. 登录 Songloft 管理端，打开 JS 插件管理页面。
3. 上传 `dist/gdstudio.jsplugin.zip`；同一 `entryPath` 会作为覆盖更新处理。
4. 刷新插件页面，确认版本、搜索、试听和下载状态正常。

插件要求 Songloft `2.11.0` 或更高版本。完整需求与边界见 `SPEC.md`，版本变化见 `CHANGELOG.md`，开发约定见 `AGENTS.md`。

## 已知限制

- 所有搜索和解析均依赖第三方上游服务，其可用性、数据完整度和返回格式可能变化。
- 网易云或其他来源网络超时时会自动重试一次，第二次仍失败才向用户展示友好提示。
- 插件不保证所有付费、会员或受地区限制的内容都能获得可播放地址。
- 主播放器全屏跳转依赖客户端导航桥接；不支持该桥接的客户端仍会启动播放，但可能不会自动切换页面。

## 使用边界

本项目仅面向个人使用或小范围私有、非商业部署。请仅访问和保存你有权使用的内容，并自行遵守所在地法律、GDStudio 服务规则和各音乐来源条款。

插件页面明确提示“仅供个人研究 · 禁止传播”。该提示不构成免责或授权；用户仍须确保访问、试听和保存的内容已获合法授权。

每次进入插件页面都会展示完整使用须知，用户必须勾选“已阅读并同意”后才能进入功能页面。

音质降级和数据映射行为参考 `musicdl 2.13.4`。网易云与酷我优先使用 GDStudio 官方公开 API；酷我同源备用解析方式参考 `CharlesPikachu/musicsquare`，腾讯搜索和解析使用 musicdl `QQMusicClient` 已收录的 Tang 同源接口。插件不安装、打包或运行 Python/musicdl。相关来源和非商业使用说明详见 `LICENSE` 与 `NOTICE`。
